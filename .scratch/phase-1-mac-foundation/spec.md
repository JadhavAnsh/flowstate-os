# Phase 1 — Mac Foundation

Source: [FlowState-OS.md](../../FlowState-OS.md) §65 (Phase 1 — Mac Foundation).

**Goal:** A user can speak naturally to FlowState and interact with models through the local runtime.

**In scope (Phase 1 deliverables):** Tauri shell, React desktop app, Rust runtime (FlowState Core), SQLite, voice HUD, streaming voice, model abstraction, BYOK, secure credential vault, local event bus, conversation/task persistence.

**Out of scope (later phases):** coding agent, computer control, Skills/MCP, full model router modes, wake word, non-macOS platforms.

**Depends on:** Phase 0 protocol (`packages/protocol`, `flowstate-protocol`) — complete.

**Tickets:** numbered issues under `issues/`; work the frontier (unblocked + `ready-for-agent`).
